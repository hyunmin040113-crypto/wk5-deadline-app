# 틈 · 이동 시간을 내 시간으로

출퇴근 이동 중 원하는 활동을 선택해 시작하고, 환승이나 이탈로 잠시 멈춰도 마지막 지점(RETURN POINT)에서 다시 이어가도록 설계한 모바일 웹 UX 프로토타입입니다. 핵심 흐름은 활동 선택 → 시작 → 중단 → 복귀 → 완료입니다.

## 프로젝트 소개

PRD와 사용자 시나리오에서 출발해, 이동 시간과 환승 때문에 원하는 활동을 시작하거나 이어가기 어려운 문제를 다룹니다. 프로토타입은 실제 서비스 연동보다 사용자가 이동 중 활동을 선택하고 다시 돌아오는 경험을 살펴볼 수 있도록 구성되어 있습니다.

## 사용한 도구와 기술

- React, TypeScript, Vite
- Lucide React 아이콘
- 브라우저 LocalStorage (활동 설정, 진행 상태, 기록 저장)
- pnpm lockfile로 의존성 버전 관리

## 핵심 기능

- 출근길·퇴근길 활동 선택과 연결 서비스 설정
- 도보, 승강장 대기, 활동, 환승 안내, 환승, RETURN POINT, 완료로 이어지는 시나리오
- 활동 중 다른 앱으로 이탈했을 때 원래 활동을 상기시키는 퇴근길 흐름
- 활동의 마지막 진행 지점 표시와 복귀 경험
- 완료 시간·진행 범위 및 활동 기록 보기
- 시나리오 시뮬레이터로 실제 시간을 기다리지 않고 다음 상황 진행
- 설정과 완료 기록을 브라우저 LocalStorage에 유지

## 실행 방법

Node.js 20 이상 환경에서 프로젝트 폴더에서 실행합니다.

```bash
pnpm install
pnpm dev
```

배포용 빌드는 `pnpm build`, 빌드 미리보기는 `pnpm preview`로 실행합니다. npm을 사용하는 경우에도 `npm install`, `npm run dev` 등 `package.json`의 스크립트를 사용할 수 있습니다.

## 시나리오 체험

- 오늘 화면에서 출근길 또는 퇴근길 활동을 고릅니다.
- 화면 흐름에 따라 활동 시작, 환승 전 안내, 환승, RETURN POINT, 완료 기록을 체험합니다.
- 퇴근길 흐름에서는 `다른 앱을 열었어요`를 눌러 이탈 상기와 복귀 제안을 확인합니다.
- 화면 오른쪽 시뮬레이터의 `다음 상황으로` 버튼을 누르면 흐름을 진행할 수 있습니다. 모바일에서는 우측 `TEST` 탭 또는 상단 메뉴 버튼으로 시뮬레이터를 엽니다.

## 프로젝트 구조

```text
index.html           앱 진입 HTML
src/main.tsx         React 진입점
src/App.tsx          화면, 시나리오 상태와 사용자 인터랙션
src/styles.css       데스크톱 및 모바일 스타일
vite.config.ts       Vite 설정
```

## 프롬프트와 작업 회고

### 효과적이었던 프롬프트

구현 계획 작업에서 PRD와 사용자 시나리오를 각각 요구사항과 화면 흐름의 기준으로 지정하고, 문서 간 충돌은 먼저 알리며 문서에 없는 기능은 추가하지 말라고 요청했습니다. 또한 핵심 경험을 **활동 선택 → 시작 → 흐름 유지 → 중단 후 복귀 → 기록 확인**으로 한정하고, 먼저 계획을 검토한 뒤 구현하도록 단계를 나눴습니다. 실제 대화 기록에서 확인되는 프롬프트의 요지를 정리했습니다.

### 수정이 필요했던 시도

- 모바일 홈 헤더는 가운데 ‘홈’ 제목을 추가하고 작은 제목 줄을 제거하는 방향으로 수정했지만, 실제 화면을 본 뒤 가운데 ‘홈’ 글자 자체를 다시 제거했습니다. 첫 헤더 조정이 최종 선호와 맞지 않아 화면을 확인하고 재수정한 사례입니다.
- 승강장 화면의 뒤로 가기 동작도 처음에는 다른 화면으로 돌아가거나 제거하는 식으로 조정됐다가, 시나리오상 직전 단계로 연결하도록 다시 수정했습니다. 화면 단위로 버튼 동작을 지정하고 전체 흐름에서 확인하는 과정이 필요했습니다.

위 사례는 ‘실패’라기보다 구현 후 사용자 피드백으로 방향을 바로잡은 반복 수정입니다. 해당 작업 기록에서 확인되는 사례만 적었습니다.

## 남은 한계

- 열차 도착 및 환승 알림, SNS 이탈 감지, 외부 앱 실행은 UI 시뮬레이션이며 교통정보나 외부 서비스와 연결되지 않습니다.
- 전자책·영상의 진행 지점과 활동 시간은 시나리오용 예시 데이터입니다. 실제 앱의 콘텐츠 상태를 읽거나 동기화하지 않습니다.
- 서비스는 로그인이나 백엔드 없이 동작하며 저장 데이터는 현재 브라우저의 LocalStorage에 한정됩니다.
- 실제 이동 환경에서의 알림 제공, 접근성, 다양한 경로와 혼잡도 대응은 검증이 더 필요합니다.

## 저장 데이터 초기화

브라우저 개발자 도구의 Application/Storage에서 현재 사이트의 `teum.activities`, `teum.logs`, `teum.run` 항목을 지우면 초기 데이터로 돌아갑니다.
